# Черная пятница в SHKOLA — анимированный пост

Концепция «Дневник без оценок»: лаймовый маркер закрашивает двойки и замечания
в дневнике, вместо них появляются скидки. Фирменный зелёный стиль.
Квадрат 1080×1080, 11,5 сек, 30 fps, без звука.

- `shkola_black_friday_20nov.mp4` — «Акция действует только до 20 ноября»
- `old-pink/`, `old-green/` — предыдущие версии (не актуальны)

## Перерендер с другой датой

```bash
cd black-friday
npm install
node render.js 20 shkola_black_friday_20nov.mp4   # число ноября, имя файла
```
Нужны Node, Playwright (Chromium) и ffmpeg.
