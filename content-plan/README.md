# Контент-план SMM

Веб-приложение для планирования публикаций: неделя/месяц/по статусам, идеи, архив, боковая панель редактирования, адаптации под разные площадки, экспорт и импорт данных в JSON.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`) в браузере.

Для автономного файла без dev-сервера:

```bash
npm run build
npm run preview
```

`npm run preview` поднимает локальный сервер для папки `dist` — открывать `dist/index.html` напрямую через `file://` не рекомендуется (браузеры блокируют модули JS при таком открытии).

## Хранение данных

Все данные хранятся только в `localStorage` этого браузера на этом устройстве и не синхронизируются между устройствами. Экспортируйте JSON регулярно (кнопка «Данные» в боковой панели → «Экспортировать данные») для резервной копии.
