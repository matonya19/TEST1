# «Коробка SHKOLA» — ролик Чёрной пятницы (−50% на первый месяц)

- `shkola_korobka_1080x1920.mp4` — готовый ролик 9:16, 28,5 сек, голоса + звуки, без музыки.
- `keyframes/` — ключевые кадры, `clips/` — клипы Kling 2.5 Turbo Pro, `voices/` — голоса (ElevenLabs v3) и итоговая дорожка `_mix.wav`.
- `src/` — запросы к fal.ai и монтажный план (`plan.json`); облачка и финал собираются тем же `overlay.html`, что в `mama-ad/src/`,
  с текстами финала «Начните с пробного урока / −50% на первый месяц обучения».
