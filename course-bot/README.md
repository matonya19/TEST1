# Бот курса интервью

Бот публикует в **ветку (тему) Telegram-группы**:

- **пост дня** по расписанию 3-недельного курса: видео + описание (или просто текст, фото, файл);
- **напоминания** об эфирах и офлайн-встречах: за день, за час, в момент начала — как настроите.

Сервер не нужен: бот запускается в GitHub Actions каждые 15 минут, проверяет расписание и отправляет то, что пора. Что уже отправлено, он записывает в `data/sent.json`, поэтому ничего не придёт дважды.

Всё содержимое курса — в одном файле **`course.yaml`**.

```
🔔 Через 1 час — Эфир «Как отвечать на вопрос о зарплате»

🗓 26 ноября (четверг) в 19:00
🔴 https://…
Подключайтесь, готовьте вопросы!
```

## Что нужно от вас

### 1. Бот (5 минут)
1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → получите **токен**.
   *Можно использовать бота статистики, который уже есть, но отдельный бот аккуратнее: у курса своё имя и аватарка.*
2. В GitHub: **Settings → Secrets and variables → Actions → Secrets → New repository secret**
   имя `COURSE_BOT_TOKEN`, значение — токен.

### 2. Группа и ветка
1. Добавьте бота в группу и сделайте **администратором** (достаточно права «Отправка сообщений»; для закрытых тем нужно «Управление темами»).
2. В нужной ветке напишите `/id@имя_вашего_бота`.
3. В GitHub: **Actions → Course bot → Run workflow**, выберите `discover` → Run.
   В итогах запуска будут **ID группы** (`-100…`) и **номер ветки**.
4. **Settings → Secrets and variables → Actions → Variables**:
   - `COURSE_CHAT_ID` = ID группы;
   - `COURSE_THREAD_ID` = номер ветки (если в группе нет тем, не создавайте эту переменную — посты пойдут в общий чат).
5. Запустите `test` — в ветке появится «✅ Бот курса подключён».

### 3. Видео
Лучший способ — **file_id**: видео хранится в Telegram, в репозиторий ничего не загружается, размер до 2 ГБ.
1. Пришлите все видео курса боту **в личку** (можно с подписью «день 1», чтобы не запутаться).
2. Запустите `discover` — в разделе «ФАЙЛЫ» будут длинные коды `BAACAgI…`.
3. Вставьте код в `course.yaml`: `video: "BAACAgI…"`.

> `discover` видит сообщения только за последние ~24 часа. Если видео много, присылайте их порциями и запускайте `discover` после каждой.

Другие варианты: ссылка `video: "https://…/day1.mp4"` (до 20 МБ) или файл в папке `course-bot` (до 50 МБ, но тогда видео будет лежать в репозитории).

### 4. Контент — `course.yaml`
- `start_date` — дата первого дня курса;
- `post_time` — время поста по умолчанию;
- в `posts` для каждого дня (1–21) — `text` и `video`; у отдельного поста можно указать своё `time`, а для двух постов в день достаточно сделать два блока с одним `day`;
- в `events` — эфиры и офлайн-встречи: дата/время, ссылка или адрес, когда напоминать;
- когда всё готово — `enabled: true`.

Посты, в которых осталось слово «ЗАМЕНИТЕ», бот **не отправит**: это защита от недозаполненных шаблонов.

Тексты пишутся с HTML-разметкой: `<b>жирный</b>`, `<i>курсив</i>`, `<a href="https://…">ссылка</a>`. Если разметка где-то сломается, бот отправит текст без форматирования, а не упадёт.

### 5. Проверка перед стартом
- **Actions → Course bot → Run workflow → `preview`** — всё расписание с датами; ⚠️ отмечены незаполненные посты.
- Чтобы посмотреть, как выглядит пост, не показывая его группе: создайте переменную `COURSE_TEST_CHAT_ID` = ваш личный ID (его тоже покажет `discover`, если написать боту в личку), затем `test` с полем `day` = номер дня.

## Как это работает

| Ситуация | Что делает бот |
|---|---|
| Пришло время поста | Отправляет в течение ~15–30 минут (GitHub запускает расписание с задержкой) |
| Бот не запускался несколько часов | Догоняет пропущенные посты, но не старше `catch_up_hours` (12 ч) |
| Напоминание опоздало больше чем на час или встреча уже идёт | Пропускает, чтобы не было бессмысленных напоминаний |
| Изменили текст уже отправленного поста | Повторно не отправляет |
| Перенесли встречу на другое время | Напомнит по новому времени |
| Ошибка Telegram на одном посте | Остальные всё равно уйдут, запуск помечается красным, и GitHub пришлёт письмо |

## Запуск на своём компьютере (необязательно)

```bash
cd course-bot
pip install -r requirements.txt
python course_bot.py preview
COURSE_BOT_TOKEN=… python course_bot.py discover
COURSE_BOT_TOKEN=… COURSE_CHAT_ID=… COURSE_THREAD_ID=… python course_bot.py test
```
