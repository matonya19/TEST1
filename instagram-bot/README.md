# Instagram-бот для Натальи Перепелицы

Отвечает клиентам в директе Instagram с помощью Claude, опираясь на сведения из `knowledge.md`.

- Отвечает коротко и вежливо, на языке клиента.
- Не выдумывает: если ответа нет в `knowledge.md`, обещает передать вопрос Наталье.
- Помнит историю переписки с каждым клиентом (файл `conversations.db`).
- **Если Наталья сама ответила клиенту**, бот замолкает в этом диалоге на 12 часов (настраивается).

## Запуск

1. Заполните `knowledge.md` — услуги, цены, как записаться, частые вопросы.
2. Скопируйте `.env.example` в `.env` и впишите ключи.
3. Установите и запустите:
   ```bash
   pip install -r requirements.txt
   uvicorn app:app --host 0.0.0.0 --port 8000
   ```
4. Бот должен быть доступен из интернета по HTTPS (Render, Railway, VPS; для теста — `ngrok http 8000`).

## Настройка Instagram

1. Аккаунт Натальи должен быть **профессиональным** (Бизнес или Автор).
2. На [developers.facebook.com](https://developers.facebook.com) создайте приложение типа **Business**
   и добавьте продукт **Instagram → API setup with Instagram login**.
3. Подключите аккаунт Натальи и сгенерируйте токен → `IG_ACCESS_TOKEN`.
   Секрет приложения (App settings → Basic) → `IG_APP_SECRET`.
4. В разделе **Webhooks** укажите:
   - Callback URL: `https://ваш-адрес/webhook`
   - Verify token: значение `IG_VERIFY_TOKEN` из `.env`
   - подпишитесь на поле **messages**.
5. В приложении Instagram: Настройки → Сообщения → разрешите доступ к сообщениям для подключённых инструментов.
6. Пока приложение в режиме разработки, бот отвечает только аккаунтам, добавленным в роли тестировщиков.
   Для всех клиентов нужна проверка приложения (App Review) с разрешением `instagram_business_manage_messages`.

## Ограничения Instagram

- Бот может ответить только в течение 24 часов после последнего сообщения клиента.
- Первым писать клиентам бот не может.
