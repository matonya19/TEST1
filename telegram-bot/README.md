# Telegram-бот «ДНК-здоровье»

Кнопочный бот по сценарию «Полный сценарий для настройки». Без Salebot: свой код, свой сервер.

- Все экраны, тексты и кнопки — в `screens.py`. Поменять текст = поправить файл и перезапустить бота.
- Постоянное меню внизу: Программа · Стоимость · Вопросы · В начало. Команды /start /menu /price /help /stop.
- «Хочу начать» → согласие → заявка уходит **в чат ассистента**. Повторное нажатие не создаёт дубль.
- Вопросы клиентов тоже уходят ассистенту. Если отправить не удалось — клиент видит ошибку, а не «передали».
- **Ассистент отвечает клиенту прямо из своего чата:** нажимает «Ответить» (Reply) на уведомление бота,
  пишет текст — бот пересылает его клиенту. Работает даже если у клиента нет @username.
- Серия из 3 сообщений (через 1, 3 и 7 дней) — только если клиент сам согласился. /stop её отменяет,
  после заявки она останавливается.
- Источник перехода: ссылка `t.me/ИМЯ_БОТА?start=instagram` запомнит, что клиент пришёл из Instagram
  (можно делать свои метки: `?start=reels`, `?start=ads`).
- Команда /stats в чате ассистента — сколько людей открыли бота, смотрели цену, оставили заявку за 14 дней.

## Что нужно сделать (один раз)

1. **Создать бота.** В Telegram откройте @BotFather → `/newbot` → придумайте имя («ДНК-здоровье»)
   и адрес (например, `dna_perepelitsa_bot`). BotFather пришлёт **токен** — это `TELEGRAM_BOT_TOKEN`.
   Там же можно поставить аватарку (`/setuserpic`) и описание (`/setdescription`).
2. **Чат ассистента.** Создайте группу (например, «Заявки ДНК»), добавьте туда ассистента и бота.
   Напишите в группе `/chatid` — бот ответит числом вида `-100…`. Это `ASSISTANT_CHAT_ID`.
3. Скопируйте `.env.example` в `.env` и заполните.
4. Запустите:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```
   Боту не нужен свой адрес в интернете — достаточно, чтобы он постоянно работал на сервере
   (VPS, Railway, Render, Timeweb Cloud и т.п.). Пока программа запущена — бот работает.
