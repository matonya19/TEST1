# «Мама, у тебя опять школа» — ролик Чёрной пятницы SHKOLA

- `shkola_mama_chai_1080x1920.mp4` — готовый ролик 9:16, 30 сек, со звуком.
- `keyframes/` — ключевые кадры (nano-banana через fal.ai), `storyboard.jpg` — раскадровка.
- `clips/` — исходные клипы Kling 2.5 Turbo Pro (image-to-video, по 5 сек).
- `src/` — запросы к fal.ai (`f*.json` картинки, `v*.json` видео), `fal.py` — клиент очереди fal.ai,
  `plan.json` — монтаж (обрезка клипов, облачка с репликами, финал), `overlay.html` — облачка и финальная карточка
  (логотип подставляется вместо `LOGO_SRC`), `compose.js` — сборка, `sfx_mama.py` — старые синтезированные звуки (не используются).
- `sounds/` — звуки ElevenLabs (через fal.ai), `_mix_no_music.wav` — итоговая дорожка без музыки.
- Сцена 4 перегенерирована (`v4n`): мама в отчаянии, а не радуется.
